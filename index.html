Rota Viva Viagens

Assistente financeiro para decidir sua viagem

Dados fictícios
Ambiente de demonstração. Contas, saldos e transações são inventados (formato Plaid Sandbox) e a Rota Viva é uma agência fictícia. Valores em US$, com conversão para R$ à taxa fixa de demonstração de 1 US$ = R$ 5,50, que não é cotação real. Não representa o Open Finance brasileiro. Nunca digite senha, código ou número de cartão.
Projeto de estudo (desafio DIO - MCP com Pluggy e Plaid). Dados locais e fictícios, nenhuma chave de API neste site.
