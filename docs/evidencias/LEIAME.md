# Evidências

Print de tela vale muito no portfólio, porque mostra que tudo funciona. Esta pasta tem hoje:

| Arquivo | O que é |
|---|---|
| [`conversa-exemplo.md`](conversa-exemplo.md) | Respostas reais do assistente, geradas por `npm run exemplo` a partir dos dados fictícios |

## O que você ainda precisa adicionar aqui (prints seus)

Os prints dependem da sua conta e do seu computador, por isso não vêm prontos:

1. **`mcp-pluggy-item.png`**: a IA (Codex ou outra) explicando o que é um Item, com as fontes da Pluggy, e o `/mcp` mostrando o servidor conectado.
2. **`plaid-tabelas.png`**: as tabelas de contas, saldos, transações e os três padrões de gasto, vindas do banco de Sandbox da Plaid.
3. **`app-conversa.png`**: a conversa no app publicado, mostrando o aviso de dados fictícios.

Depois de adicionar, cite os arquivos no `README.md`, na seção **Evidências**.

## Antes de publicar um print

- [ ] Nenhuma chave, token ou senha aparece (Client ID e secret inclusive)
- [ ] O caminho de pastas do seu computador não revela nada que você não queira mostrar
- [ ] Tem só dados de Sandbox, nunca de uma conta real
